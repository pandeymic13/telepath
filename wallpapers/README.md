# Your photos

Put the photos for your slideshow here, then copy them to the TV:

- Windows: `.\scripts\Sync-Wallpapers.ps1 -Apply`
- macOS and Linux: `scripts/sync-wallpapers.sh --apply`

Everything in this folder except this file is git-ignored, so your photos are never published. To keep them
somewhere else, set `wallpapers.folder` in `telepath.local.properties`.
